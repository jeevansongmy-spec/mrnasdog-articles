# Token true inflation — free dataset by MrNasdog

`true-inflation.csv` — the **true inflation** of every free coin we research on [mrnasdog.com](https://mrnasdog.com/token-supply): new coins made or unlocked, minus coins burned or bought back, as a % of the coins in circulation. Updated every day.

| column | meaning |
|---|---|
| `symbol`, `name` | the coin |
| `inflation_90d_pct` | change in circulating supply over the next 90 days, in % (positive = more coins, negative = fewer) |
| `inflation_1y_pct` | the same over the next year |
| `checked_on` | the day we last re-checked this coin's supply (YYYY-MM-DD) |
| `source_url` | the full analysis page for the coin |
